## Troubleshooting

**If drizzle-kit fails with schema mismatch:**
1. Check drizzle.config.ts configuration
2. Verify DATABASE_URL environment variable
3. May need to run `drizzle-kit push` first for existing DB

**If no changes detected:**
1. Verify all schema files are imported in index.ts
2. Check that bots.ts and other new files are being loaded
